# GripWise Demo Script (3 Minutes)

Use the shared product walkthrough for either submission. Choose a presentation emphasis from the [demo guide](DEMO_GUIDE.md) for the final explanation.

## 0:00–0:25 | The rider workspace

“GripWise helps riders keep tyre checks and maintenance records together, and gives them control over when a workshop can see an inspection.”

**Show:** Sign in as a rider, open the vehicle list, and start an inspection with an image you are allowed to use.

## 0:25–1:05 | Explain the inspection result

“This report shows the current prototype output and the next suggested action. In this demo configuration the provider is mock: it does not analyze the image, so this result is not an AI assessment or a tread-depth measurement. A physical inspection by a qualified mechanic is still needed.”

**Show:** The report’s image-quality status, recommendation, and demo disclosure. Avoid presenting the simulated score as a real measurement.

## 1:05–1:45 | Rider-controlled workshop access

“A rider can share an inspection with a workshop by granting access. The rider can also revoke that access from Mechanic Access.”

**Show:** Copy the mechanic’s full Workshop ID from the Service Queue, enter it under the rider’s Mechanic Access page, and grant consent.

## 1:45–2:20 | The workshop workflow

“The inspection appears in the mechanic’s queue after the rider authorizes access. The mechanic can review the report, add physical findings, and record service work.”

**Show:** Open the authorized inspection. Enter a measurement only if it was actually taken for this demonstration; otherwise explain the field without saving invented findings.

## 2:20–2:50 | Mechanic Growth

“Mechanic Growth supports profile completion, general tyre-care learning, quiz progress, recognition from recorded activity, and customer follow-ups only when the customer has agreed.”

**Show:** The profile checklist and learning modules. Use only accurate profile details. If demonstrating a follow-up, use a clearly labelled demo record and leave customer contact information blank.

## 2:50–3:00 | Close the trust loop

“GripWise brings rider records and workshop service together while keeping access with the rider. This is a prototype; it does not claim validated AI accuracy, professional certification, or a confirmed partner programme.”

**Show:** Return to Mechanic Access and revoke access if that is part of the demonstration.
