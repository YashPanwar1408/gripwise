## Phase 2 — Real CV Pipeline (Sprints 4–5, ~5 days)

**Goal:** CVProvider wraps adapted tyreHealth algorithms behind the InferenceProvider interface. Quality gating works. Results carry honest confidence tiers.

### 2.1 AI Inference — CVProvider

| Task | Notes |
|---|---|
| Write `gripwise/ai/tyre_pipeline/quality_checker.py` | Blur (Laplacian), brightness, min resolution, MIME check |
| Write `gripwise/ai/tyre_pipeline/detector.py` | Adapted from tyreHealth detection.py; YOLO→Hough fallback; new tyre-specific YOLO if weights available |
| Write `gripwise/ai/tyre_pipeline/tread_analyser.py` | Adapted from tread_analysis.py; explicit uncertainty on output |
| Write `gripwise/ai/tyre_pipeline/anomaly_detector.py` | Reimplemented; confidence score not binary flag; requires quality gate before running |
| Write `gripwise/ai/providers/cv_provider.py` | Wraps all sub-modules; sets confidence tiers from image quality and algorithm state |
| GRIPWISE_INFERENCE_PROVIDER env switch | "mock" default; "cv_pipeline" opt-in |
| Unit tests for each sub-module (synthetic images) | From audit: synthetic tests are acceptable for algorithm coverage |
| Integration test: cv_provider.analyse(real_tyre_image) | At least one real tyre image in test fixtures |

### 2.2 Confidence Tier Derivation Rules (CVProvider)

| Observation Field | HIGH | MEDIUM | LOW | NOT_AVAILABLE |
|---|---|---|---|---|
| tread_score | quality=PASS AND detected_tyres>=1 | quality=DEGRADED OR detected_tyres=0 with Hough fallback | quality=FAIL | exception during analysis |
| anomaly_detected | quality=PASS AND tyre clearly detected | quality=DEGRADED | quality=FAIL or very low detection confidence | exception |
| condition_class | CNN weights present AND quality=PASS | CNN weights present AND quality=DEGRADED | — | CNN weights absent |

### 2.3 Backend Updates

| Task | Notes |
|---|---|
| Add model_version to InferenceResult (semver of ai/ package) | Stored in inspections table |
| Update POST /api/ai/health to report per-algorithm availability | Honest report of what is and is not working |
| Background task queue for CV inference (FastAPI BackgroundTasks) | Keeps POST /api/inspections fast |

### Milestone 2 — Definition of Done (Completed)

- [x] CVProvider returns real tread score and anomaly observation on a clear tyre photo.
- [x] Confidence tiers match the derivation rules table above.
- [x] Mock provider still passes all tests.
- [x] Switching providers requires only an env variable change.
- [x] No raw percentage presented without caveat text in the UI.
- [x] POST /api/ai/health correctly reports condition_classifier_available=false (weights absent).

## Unresolved Risks

| Risk | Probability | Impact | Mitigation |
|---|---|---|---|
| Real tyre model weights not available | High | Medium | Mock provider ensures demo works regardless; honest labelling covers gap |
| AGPL-3.0 from ultralytics | Medium | High | Use yolov8n.pt only for local demo; resolve before any distribution |
| Single-subject driver monitoring | High | Medium | Disclosed in UI; scope as research prototype |
| IDD dataset non-commercial restriction | Medium | High | Do not ship indian_hazards.pt without permission; use yolov8n.pt fallback |
| FastAPI + Next.js integration complexity | Low | Low | Standard pattern; well documented |
